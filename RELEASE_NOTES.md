## 🌟 What's New in v3.5.0

This release brings **professional-grade diagnostic and management tools** to Wethereal, making it the most complete Windows optimization solution available.

### 🆕 New Professional Tools

#### 1. 🏥 Comprehensive System Health Check

A complete 10-point diagnostic system that analyzes your system's health:

- ✅ **Disk Health Analysis** - Check free space and identify storage issues
- ✅ **Memory Usage Monitoring** - Track RAM consumption
- ✅ **Windows Update Status** - Verify update service health
- ✅ **Antivirus Protection Check** - Ensure security is active
- ✅ **System Uptime Tracking** - Monitor stability
- ✅ **Event Log Error Analysis** - Identify system errors
- ✅ **Startup Program Count** - Track boot impact
- ✅ **Temporary Files Size** - Identify cleanup opportunities
- ✅ **Network Connectivity Test** - Verify internet connection
- ✅ **System File Integrity** - Check Windows health

**Health Score**: Get a 0-100 score with color-coded indicators and automated recommendations!

#### 2. 📝 Registry Optimizer

Safe, tested registry tweaks for better performance:

- Menu show delay reduction (faster context menus)
- Aero Shake disable (prevent accidental window minimization)
- Snap Assist optimization (smoother window snapping)
- Taskbar animations disable (faster taskbar)
- Icon cache optimization (faster icon loading)
- Thumbnail cache tuning (faster folder browsing)
- Windows Search optimization (better search performance)
- Cortana disable (privacy & performance)

**Automatic Backup**: All changes are backed up before modification!

#### 3. ⚙️ Intelligent Service Optimizer

Smart service management that knows what's safe to disable:

- Identifies non-essential services
- Automatic service state backup
- Telemetry service removal
- Xbox services optimization (for non-gamers)
- Superfetch/SysMain control
- Windows Search management
- Detailed optimization reporting

#### 4. 🔄 Windows Update Manager

Complete control over Windows Updates:

- Pause updates (7 or 30 days)
- Resume updates
- Check for updates on-demand
- Disable/Enable automatic updates
- Update service management
- Safety warnings for critical changes

### ✅ Code Quality Improvements

**All PowerShell Warnings Fixed!** The entire codebase now follows PowerShell best practices:

- ✅ All functions use approved verbs
- ✅ Zero PSScriptAnalyzer warnings
- ✅ Production-ready code quality
- ✅ Professional naming conventions

**12 Functions Renamed**:

- `Apply-*` → `Invoke-*`
- `Configure-*` → `Set-*`
- `Run-*` → `Start-*`
- `Clean-*` → `Clear-*`
- `Manage-*` → `Set-*` or `Update-*`

## 🚀 Installation

### Quick Install

1. Download `Wethereal-v3.5.0.zip` from the releases page
2. Extract to your desired location
3. Right-click `Win-Tweaker.ps1` → **Run with PowerShell (as Administrator)**
4. Enjoy!

## 🔄 Upgrade from v3.0.0

If you're upgrading from v3.0.0:

1. **Backup your current settings** (Option 14)
2. **Download v3.5.0**
3. **Replace all files** with new version
4. **Run the script** - All your backups are preserved!

Your previous backups and logs will be automatically detected and remain available.
